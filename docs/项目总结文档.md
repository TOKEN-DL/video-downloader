# 万能视频下载网站 — 项目总结文档

## 项目概述

基于 Vue 3 + FastAPI + yt-dlp 构建的万能视频下载网站，支持 1000+ 平台的视频解析与下载。采用 Apple.com.cn 风格 UI，移动端友好。

## 技术架构

```
┌─────────────────────────────────────────────┐
│                  Frontend                    │
│          Vue 3 + Vite + Tailwind CSS         │
│              Apple-style UI                  │
└────────────────────┬────────────────────────┘
                     │ HTTP API
┌────────────────────▼────────────────────────┐
│                  Backend                     │
│            FastAPI (Python)                  │
│  ┌─────────────┐  ┌──────────────────────┐  │
│  │   yt-dlp    │  │   douyin_service     │  │
│  │ (通用解析)   │  │ (抖音专用解析)        │  │
│  └─────────────┘  └──────────────────────┘  │
│         │                   │                │
│         ▼                   ▼                │
│    ffmpeg 合并         iesdouyin.com         │
│   (DASH音视频)         (无需Cookie)          │
└─────────────────────────────────────────────┘
```

## 核心功能

### 1. 视频解析 (`POST /api/parse`)
- 输入 URL，返回视频标题、封面、可用画质列表、字幕信息
- 通用平台：yt-dlp 解析（YouTube、Bilibili、Twitter 等 1000+ 平台）
- 抖音：自动检测 yt-dlp 失败后，使用本地 `douyin_service` 兜底解析

### 2. 视频下载 (`POST /api/download`)
- 通用下载：yt-dlp 下载，自动合并 DASH 音视频流为 MP4
- 抖音下载：httpx 流式下载，实时进度追踪
- 后台线程执行，通过轮询获取进度

### 3. 进度追踪 (`GET /api/download/status/{task_id}`)
- 实时显示：下载百分比、速度、已下载大小、预估剩余时间
- 前端每秒轮询一次

### 4. 图片代理 (`GET /api/proxy/image`)
- 代理平台 CDN 图片，绕过 Referer 防盗链

## 关键技术决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 视频下载引擎 | yt-dlp | 支持 1000+ 平台，社区活跃 |
| DASH 音视频合并 | ffmpeg | Bilibili/抖音使用分离的音视频流 |
| 抖音解析方案 | iesdouyin.com 分享页 | 无需 Cookie、无需 JS 引擎、零外部依赖 |
| 进度追踪 | 内存 dict + 轮询 | 简单可靠，满足单机部署场景 |
| 图片防盗链 | 后端代理 | 平台 CDN 检查 Referer，前端无法绕过 |

## 已验证平台

| 平台 | 解析 | 下载 | 音频 | 备注 |
|------|------|------|------|------|
| Bilibili | yt-dlp | yt-dlp + ffmpeg | h264+aac | DASH 格式自动合并 |
| YouTube | yt-dlp | yt-dlp + ffmpeg | h264+aac | 多画质选择 |
| 抖音 | douyin_service | httpx 流式下载 | h264+aac | 无需 Cookie |
| Twitter/X | yt-dlp | yt-dlp + ffmpeg | 预期支持 | — |

## 本地开发启动

```bash
# 后端
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8003 --reload

# 前端
cd frontend
npm install
npm run dev
```

前端 Vite 配置了代理，`/api/*` 请求自动转发到后端 8003 端口。
