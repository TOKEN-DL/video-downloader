# 时雨视频分析网站 — 项目总结文档

> 最后更新：2026-05-19

## 项目概述

基于 Vue 3 + FastAPI + yt-dlp 构建的时雨视频分析网站，支持 1000+ 平台的视频解析与下载，集成 AI 视频总结功能。采用 Apple.com.cn 风格 UI，移动端友好。

## 核心功能

### 1. 视频解析 (`POST /api/parse`)
- 输入 URL，返回视频标题、封面、可用画质列表、字幕信息
- 通用平台：yt-dlp 解析（YouTube、Bilibili、Twitter 等 1000+ 平台）
- 抖音：自动检测 yt-dlp 失败后，使用本地 `douyin_service` 兜底解析

### 2. 视频下载 (`POST /api/download`)
- 通用下载：yt-dlp 下载，自动合并 DASH 音视频流为 MP4
- 抖音下载：httpx 流式下载，实时进度追踪
- 后台线程执行，通过轮询获取进度

### 3. 进度追踪 (`GET /api/download/status/{task_id}`)
- 实时显示：下载百分比、速度、已下载大小、预估剩余时间

### 4. 图片代理 (`GET /api/proxy/image`)
- 代理平台 CDN 图片，绕过 Referer 防盗链

### 5. AI 视频总结 (`POST /api/ai/summarize`) ✅ 新增
- 后台线程提取字幕 → DeepSeek API 生成结构化总结
- 返回：摘要、核心要点（带时间戳）、关键术语、深度思考问答
- 自动生成思维导图（markmap 格式）
- 字幕数据带时间戳，前端逐行显示

### 6. AI 对话 (`POST /api/ai/chat`) ✅ 新增
- 基于视频字幕上下文的智能问答
- 支持多轮对话，自动携带最近 10 条消息

### 7. 导出 (`GET /api/ai/export/{task_id}`) ✅ 新增
- Markdown 格式导出
- PDF 格式导出（reportlab，支持中文）

## 关键技术决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 视频下载引擎 | yt-dlp | 支持 1000+ 平台，社区活跃 |
| DASH 音视频合并 | ffmpeg | Bilibili/抖音使用分离的音视频流 |
| 抖音解析方案 | iesdouyin.com 分享页 | 无需 Cookie、无需 JS 引擎、零外部依赖 |
| 进度追踪 | 内存 dict + 轮询 | 简单可靠，满足单机部署场景 |
| 图片防盗链 | 后端代理 | 平台 CDN 检查 Referer，前端无法绕过 |
| AI 模型 | DeepSeek API | OpenAI 兼容接口，中文能力好，性价比高 |
| AI 输出格式 | 结构化 JSON | 便于前端分类展示（摘要/要点/术语/问答） |
| 思维导图 | markmap-lib + markmap-view | Markdown 驱动，轻量，无需额外服务 |
| PDF 导出 | reportlab | Python 原生，支持中文字体注册 |
| 字幕提取 | B站弹幕API + yt-dlp 双路径 | B站走平台API更快，其他平台走yt-dlp |
| Markdown 渲染 | marked.js | 轻量快速，支持 GFM |

## AI 总结数据流

```
用户点击 "AI 总结"
    │
    ▼
POST /api/ai/summarize  →  返回 task_id
    │
    ▼  (后台线程)
    ├── parse_video(url)           → 获取视频标题
    ├── get_subtitle_data(url)     → 提取带时间戳字幕 [{time, text}]
    ├── ai_service.summarize()     → DeepSeek API → 结构化 JSON
    └── ai_service.generate_mindmap_markdown() → 思维导图 Markdown
    │
    ▼  (前端轮询 1.5s)
GET /api/ai/summarize/status/{task_id}
    │
    ▼
前端渲染：总结Tab / 字幕Tab(带时间戳) / 思维导图Tab / AI问答Tab
```

## 本地开发启动

```bash
# 后端
cd backend
pip install -r requirements.txt
python main.py    # 启动在 0.0.0.0:8000（支持 --reload）

# 前端
cd frontend
npm install
npm run dev       # 启动在 localhost:5173，代理 /api → localhost:8000
```

### 环境变量配置（backend/.env）

```env
# AI 功能（必须配置，否则 AI 总结功能不可用）
DEEPSEEK_API_KEY=sk-xxx
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat

# 代理（可选）
PROXY=

# B站Cookie（可选，部分视频需要）
BILIBILI_SESSDATA=
```
