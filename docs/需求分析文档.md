## 一、项目背景

### 1.1 业务痛点

用户在下载保存视频到本地时，面临以下问题：

1. **平台限制**：部分视频平台不支持下载功能
2. **下载不便**：不支持批量下载、清晰度受限、下载速度慢
3. **跨平台困难**：不同平台需要不同的下载工具，切换成本高
4. **移动端缺失**：大多数下载工具仅支持桌面端，手机用户无法方便下载

### 1.2 项目目标

开发一个时雨视频分析网站，让用户能够：

- **快速**：粘贴链接即可下载，无需安装任何软件
- **随时随地**：手机浏览器直接访问，移动端友好
- **全平台覆盖**：支持 YouTube、Bilibili、抖音、Twitter 等 1000+ 平台
- **高质量**：支持多种清晰度选择，音视频完整

### 1.3 商业目标

通过免费基础功能吸引用户，通过增值服务实现盈利：

- 免费版：标清下载、单视频下载（引流）
- Pro版：4K高清、批量下载、字幕翻译、AI视频总结（付费转化）

### 3.3 功能详细说明

#### P0 - 视频URL解析

**输入**：用户粘贴视频链接（支持 HTTP/HTTPS）
**处理**：后端调用 yt-dlp 解析视频元数据
**输出**：
- 视频标题
- 视频缩略图
- 视频时长
- 作者/UP主
- 来源平台标识
- 可用格式列表（format_id, 分辨率, 文件大小）
- 可用字幕列表（语言, 是否自动生成）

**支持平台**（部分列举）：
YouTube, Bilibili, 抖音, Twitter/X, Instagram, 微博, 小红书, 快手, Facebook, TikTok, Vimeo, Pinterest 等 1000+ 平台

#### P0 - 视频下载（含音频）

**关键设计**：
- Bilibili 等平台的DASH格式是视频轨+音频轨分离的
- 下载时需要使用 yt-dlp 的 `{format_id}+bestaudio` 合并模式
- 依赖 ffmpeg 进行音视频合并
- 下载为异步任务，前端通过轮询获取进度

**下载流程**：
1. 用户选择清晰度 → 前端 POST /api/download
2. 后端创建异步下载任务 → 返回 task_id
3. yt-dlp 下载视频轨 + 音频轨 → ffmpeg 合并为 MP4
4. 前端每秒轮询 GET /api/download/status/{task_id}
5. 下载完成 → 前端 GET /api/download/file/{task_id} → 浏览器保存文件

#### P2 - 字幕下载

**功能描述**：
- 解析视频时返回可用字幕列表
- 支持手动字幕和自动生成字幕
- 支持多种字幕格式：SRT、VTT、ASS
- 字幕可独立于视频单独下载

#### P2 - 历史记录

**功能描述**：
- 每次下载完成自动记录到 SQLite
- 支持分页查询（默认每页20条）
- 展示：缩略图、标题、平台、清晰度、文件大小、下载时间
- 支持单条删除和清空全部
- 数据存储在本地 SQLite，无需额外部署数据库

## 四、非功能需求

### 4.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面首次加载 | < 3s |
| 视频解析响应 | < 10s |
| 下载速度 | 取决于视频源和用户带宽，服务端不做额外瓶颈 |
| 并发下载数 | 默认限制 5 个同时进行 |
| 文件大小限制 | 单文件最大 2GB |

### 4.2 兼容性要求

| 平台 | 最低版本 |
|------|---------|
| Chrome | 90+ |
| Safari | 14+ |
| Firefox | 90+ |
| iOS Safari | 14+ |
| Android Chrome | 90+ |
| 微信内置浏览器 | 支持 |

### 4.3 安全要求

1. 所有API需进行输入校验（URL格式、参数完整性）
2. 实施IP级限流，防止滥用
3. 下载的临时文件定时自动清理
4. 网站声明"仅供个人学习使用"
5. 支付接口需验证回调签名

### 4.4 可用性要求

1. 首页即核心功能页，无需注册即可使用
2. 操作流程 ≤ 3步：粘贴链接 → 选清晰度 → 下载
3. 错误信息清晰友好，提示用户下一步操作
4. 移动端按钮触控区域 ≥ 44px

## 五、已知约束与风险

| 风险项 | 影响 | 应对策略 |
|-------|------|---------|
| yt-dlp 更新频繁 | 部分平台extractor可能失效 | 定期更新 yt-dlp 版本 |
| 版权问题 | 法律风险 | 网站声明仅供个人学习使用 |
| 带宽成本 | 高清视频流式传输消耗大 | 考虑CDN或直链模式 |
| 平台封锁 | YouTube等需要代理 | config.py 支持代理配置 |
| ffmpeg 依赖 | 音视频合并必须 | 自动检测安装路径，缺失时提示 |
| iOS下载限制 | Safari对大文件有限制 | 提供直链跳转方案 |
| SQLite 单机 | 无法多实例部署 | 后续可迁移到 MySQL/PostgreSQL |

## 六、术语表

| 术语 | 说明 |
|------|------|
| yt-dlp | 开源视频下载工具，支持 1000+ 平台，Python库 |
| ffmpeg | 音视频处理工具，用于合并分离的视频轨和音频轨 |
| DASH | 自适应流媒体格式，视频和音频分离传输 |
| task_id | 下载任务唯一标识，用于查询进度和获取文件 |
| 进度轮询 | 前端定时（每秒）请求后端获取下载进度 |
| 毛玻璃效果 | CSS backdrop-filter 实现的半透明模糊背景 |
