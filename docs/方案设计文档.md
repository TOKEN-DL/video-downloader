## 一、技术选型

### 1.1 选型总览

| 层级 | 技术 | 版本 | 选型理由 |
|------|------|------|---------|
| 前端框架 | Vue 3 | 3.x | Composition API，生态成熟，开发效率高 |
| 构建工具 | Vite | 5.x+ | 极速HMR，开箱即用 |
| CSS框架 | Tailwind CSS | 4.x | 原子化CSS，快速实现Apple风格自定义设计 |
| 路由 | Vue Router | 4.x | Vue官方路由方案 |
| 后端框架 | FastAPI | 0.110+ | Python异步框架，原生支持异步下载和流式传输 |
| 视频引擎 | yt-dlp | latest | 1000+平台支持，活跃维护，Python原生库 |
| 音视频处理 | ffmpeg | 8.x | DASH格式音视频合并必需 |
| 数据库 | SQLite | 系统自带 | 轻量级，无需额外部署，适合单机场景 |
| 支付 | 微信/支付宝 | - | 国内主流支付方式 |

### 1.2 核心依赖关系

```
用户浏览器
    ↓
Vue 3 前端 (Vite 构建)
    ↓ HTTP API
FastAPI 后端
    ↓ Python import
yt-dlp ──→ 各视频平台 API
    ↓ 系统调用
ffmpeg (音视频合并)
```

**关键决策**：以 Python 为主要技术栈，因为 yt-dlp 是 Python 库，直接 import 使用最简单高效，避免通过 CLI 调用的开销。

## 四、API接口设计

### 4.1 视频解析 ✅

```
POST /api/parse
Content-Type: application/json

请求：{ "url": "https://www.youtube.com/watch?v=xxx" }

成功响应 (200)：
{
  "title": "视频标题",
  "thumbnail": "https://img.youtube.com/vi/xxx/maxresdefault.jpg",
  "duration": 212,
  "author": "作者名",
  "platform": "youtube",
  "formats": [
    { "format_id": "137", "resolution": "1080p", "ext": "mp4", "filesize": 52428800 },
    { "format_id": "22",  "resolution": "720p",  "ext": "mp4", "filesize": 26214400 },
    { "format_id": "18",  "resolution": "360p",  "ext": "mp4", "filesize": 13107200 }
  ],
  "subtitles": [
    { "lang": "en", "name": "English", "auto_generated": false },
    { "lang": "zh", "name": "zh (自动)", "auto_generated": true }
  ]
}

失败响应 (400)：
{ "detail": "解析失败: ERROR_MESSAGE" }
```

### 4.2 视频下载 ✅

```
POST /api/download
Content-Type: application/json

请求：{ "url": "https://...", "format_id": "137" }

成功响应 (200)：
{ "task_id": "abc123def456" }
```

### 4.3 下载进度查询 ✅

```
GET /api/download/status/{task_id}

成功响应 (200)：
{
  "status": "downloading",    # downloading / merging / done / error
  "progress": 45.2,           # 百分比
  "speed": "2.5MB/s",         # 下载速度
  "downloaded": 13107200,     # 已下载字节数
  "total": 52428800,          # 总字节数（可能为null）
  "eta": 15                   # 预计剩余秒数
}

失败响应 (404)：
{ "detail": "任务不存在" }
```

### 4.4 文件下载 ✅

```
GET /api/download/file/{task_id}

成功响应 (200)：
Content-Type: video/mp4
Content-Disposition: attachment; filename="abc123def456.mp4"
[文件流]

失败响应 (404)：
{ "detail": "文件不存在或未下载完成" }
```

### 4.5 字幕列表 ⬜

```
GET /api/subtitle/list?url=https://...

响应：
{
  "subtitles": [
    { "lang": "en", "name": "English", "auto_generated": false },
    { "lang": "zh", "name": "中文（简体）", "auto_generated": true }
  ]
}
```

### 4.6 字幕下载 ⬜

```
GET /api/subtitle/download?url=https://...&lang=en&format=srt
```

## 七、已解决的技术问题

### 7.1 DASH格式视频无音频

**问题**：Bilibili等平台的DASH格式视频轨和音频轨是分离的，直接下载视频轨没有声音。

**解决方案**：
1. 下载格式使用 `{format_id}+bestaudio/best`，让 yt-dlp 分别下载视频轨和最佳音频轨
2. 用 ffmpeg 自动合并为单个 MP4 文件
3. 下载完成后用 ffprobe 验证文件是否包含音频流
4. config.py 自动检测系统中的 ffmpeg 安装路径

**关键代码**（video_service.py）：
```python
opts["format"] = f"{format_id}+bestaudio/best"
opts["merge_output_format"] = "mp4"
opts["ffmpeg_location"] = config.FFMPEG_PATH
```

```bash

# 方案A：FastAPI托管前端
# 将 dist/ 内容放入 backend/static/
# FastAPI 配置 StaticFiles 中间件

# 方案B：Nginx分离部署（推荐）
server {
    listen 443 ssl;
    server_name your-domain.com;

    # 前端静态资源
    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # API代理到后端
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 十、风险与应对

| 风险 | 概率 | 影响 | 应对方案 |
|------|------|------|---------|
| yt-dlp extractor 失效 | 中 | 高 | 定期 `pip install --upgrade yt-dlp` |
| 平台反爬封禁 | 中 | 中 | config.py 支持代理，可配置多代理轮换 |
| 带宽成本过高 | 低 | 高 | 引入直链模式，不经过服务器中转 |
| ffmpeg 缺失 | 中 | 高 | 启动时检测，缺失时返回友好错误提示 |
| iOS 大文件下载失败 | 中 | 中 | 提供直链新窗口打开方案 |
| SQLite 并发写入冲突 | 低 | 低 | 使用 WAL 模式，后续可迁移 PostgreSQL |
